# This-Sis_Capstone

The vision behind This & Sis was to create something that would be able to show case all of my sisters' and mine hand made products. Because each of use create such differnt items we would be able to create something that would have a mutlitude of items that are great for gift giving or personal purchase without it the user having to leave to another web application. This will be an application that will have the simple interaction of searching for an item, liking that item and then contacting the paticular store for that item with requiremnts and customizations the user may want.
